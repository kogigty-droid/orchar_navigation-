1.运动规划方法分类：
1）search-based path finding 基于搜索的路径规划
{
   graph search basis
   dijkstra 和 A* 算法
   jump point search 跳点算法} 

2）sampling-based path finding 基于采样的路径规划算法
{
   probabilitc road map  概率路径图
   rapidly-exploring random tree（RRT） 快速搜索的随机树算法
   optimal sampling-based method 改进的最优化采样算法
   advanced sampling-based method 基于采样算法的一些改进版本
}

3) kinodynamic path finding  满足机器人动力学要求的路径规划方法      会考虑移动机器人简单的动力学模型
{
   state-state boundary value optimal control problem  满足两点边界值的最优控制问题
   state lattice search 状态图的搜索  （高维的dijkstra or A*）
   kinodynamic RRT*   动力学的RRT*
   hybrid A*  基于状态图搜索改进版本的混合A*算法
}
