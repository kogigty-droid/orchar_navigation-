## 1.运动规划方法分类：
1）search-based path finding 基于搜索的路径规划
{
   graph search basis   :DFS BFS
   dijkstra 和 A* 算法
   jump point search 跳点算法
}

注： 图搜索包含的 节点（node） 和 边（edge）

2）sampling-based path finding 基于采样的路径规划算法   
：先在地图上撒很多点，然后相对比较近的点连接起来，看哪些连成的边接触到了障碍物，如果有触碰的话这些边或者节点会被删除
{
   probabilitc road map  概率路径图     
   rapidly-exploring random tree（RRT） 快速搜索的随机树算法     （PRM的增量式版本）
   optimal sampling-based method 改进的最优化采样算法
   advanced sampling-based method 基于采样算法的一些改进版本
}

RRT 即使有很多采样点  到最后也很难收敛到直线的这样的一个最优路径    [随机拓展树杂乱无章]
RRT* 会在每次采样过后，对采样点的周围，对树进行重新的组织，去维护一个更短的到达起点的树，生成一条更短的路径   （显著好于RRT） [随机拓展树更加的顺滑]
<img width="1226" height="639" alt="image" src="https://github.com/user-attachments/assets/151e1dff-b0b1-4ac6-8dfb-3ffb6613b66b" />

informed RRT* 以起点和终点作为椭圆的焦点（长轴），在椭圆范围内进行采样  [专注于提升最优解]

3) kinodynamic path finding  满足机器人动力学要求的路径规划方法      会考虑移动机器人简单的动力学模型
{
   state-state boundary value optimal control problem  满足两点边界值的最优控制问题
   state lattice search 状态图的搜索  （高维的dijkstra or A*）      [代价比较高昂 稠密]
   kinodynamic RRT*   动力学的RRT*
   hybrid A*  基于状态图搜索改进版本的混合A*算法
}

## @@@ 一、常用地图结构
1. occupancy grid map 占用栅格地图
{
   most dense 最稠密
   structural 非常的结构化的
   direct index qurey  可以直接通过坐标索引查询
}


2.octo-map 八叉树地图
把很大的方块切成八块，没有障碍物的那些块块就不用继续切下去了，就没有必要去生成了

{
   sparse 稀疏的
   structural 结构化的
   indirect index query 间接的索引查询     [根据树的结构，递归的对树的儿子进行查询]
   
}

3.voxel hashing  体素哈希
根据当前格子的xyz坐标或者其他信息,通过复杂的函数 映射成一个哈希键值，这样可以插入对照表，通过哈希函数  通过这个键值去表里面查询

voxel block ---> hash table

{
   most sparse 最稀疏
   structural 结构化的
   indirect index query 间接索引查询
}

4.point cloud map 点云地图
无序的 堆叠在一起的点云  无法进行坐标索引查询的
{
   un-order
   no index query
}

PCL:  http://pointclouds.org/
丰富的应用示例，数学操作函数....   基本都收录
