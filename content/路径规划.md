### 总体框架：   
{   
   maintain a container to stored all the nodes to be visited   
   the container is initialized with the start state Xs   

   Loop   
   {   
      remove a node from the container according to some pre-defined score function   (visit a node)   
      expansion: obtain all neighbors of the node (discover all its neighbors)   
      push them into the container   
   }   
   End Loop   

   --当容器为空的时候停止循环   
   --当一个节点在容器中被删除或者拓展过 或者被访问过 它不能再被添加回容器   
   --按照什么规则去从容器中弹出当前最想要访问的节点呢？使我们尽可能快的到达终止节点/目标节点，因为这可以是我们尽可能少的去扩张我们树里面的节点   
   
}   

两种最基本的图的遍历的算法：   
graph traversal:   
depth first search (DFS) 深度优先搜索 VS. 广度优先搜索 (BFS) breadth first search       
  
1) DFS：遵循的是后进先出的规则，维护的是一个栈 stack   ------后进这个队列的会先被弹出来   
   strategy：remove/expand the deepest node in the container   
       （特点：弹出这个容器里已有的最深层级的节点  纵向！！！）   
   <img width="1045" height="670" alt="image" src="https://github.com/user-attachments/assets/6b7adbf1-1121-482c-bb72-b3de77c43d8a" />   

   步骤：   
   {   
      init container → remove node with the largest tree level → expansion → add children of expanded node into container   
      → remove node with the largest tree level(这一步回到expansion 继续这个loop循环)   
   }   

   一般DFS回溯出来的路径 不会找到最短路径   

2) BFS: 遵循先进先出的规则，维护的是一个队列 queue    -------先进这个队列的会先被弹出来   
   implementation：maintain a first in first out container   
            (实现：维护一个先进先出的容器  弹出最浅层级）

   步骤：   
   {   
      init container → remove node with the smallest tree level → expansion → add children of expanded node into container   
      → remove node with the smallest tree level (这一步回到expansion 继续这个loop循环)   
   
   }

3）贪心算法 -----启发式搜索算法   
greedy best first search   
BFS and DFS pick the next node off the frontiers base on which was "first in" or "last in"      最深或最浅   
greedy best first pick the "best" node according to some rule, called a "heuristic".       heuristic---启发式   

definition：a heuristic is a guess of how close you are to the target   
对一个节点到终点有多近的一个猜测，无法得知的  都是猜测   


会用到的合理的猜测：   
1）euclidean distance  --欧式距离        [忽略障碍物 起点到终点的距离]   
2) manhattan distance  --曼哈顿距离      [忽略障碍物 起点到终点 x的距离加上y的距离]   

贪心算法具有很强的目的性     优先拓展到终点更近的节点 更加合理   

<img width="1066" height="621" alt="image" src="https://github.com/user-attachments/assets/c82bb21e-bb52-4198-a817-00ba293cd3c3" />   

在存在障碍物的情况下：   
广度优先算法虽然查找起来比较慢，但是能够更好的找到最短路径；   （成功的前提：边缘的权重是一样的）   
贪心算法虽然找路径更快，但是带有很强的目的性，会陷入局部最优，因为贪心算法在猜测到达终点这条路径有多近的时候是忽略了障碍物的   


### @@@ 2.Dijkstra 和 A* 算法   

1）Dijkstra's algorithm:         <deque>   
strategy: expand/visit the node with cheapest accumulated cost g(n);    [弹出来的是总和最小的一个节点]   
{
   ① g(n) : the current best estimates of the accumulated cost from the start state to node "n"   
         从起点出发到当前节点的cost相加   
   ② update the accumulated costs g(m) for all unexpanded neighbors "m" of node "n"     [更新]   
   ③ a node has been expanded/visited is guaranteed to have the smallest cost from the start state [最优性保证]   
     图中任何一个被拓展过的节点，他可以保证里面所存储的g值是最小的，从起点出发到这个节点路径的累计cost。   
   
}   

<img width="1056" height="670" alt="image" src="https://github.com/user-attachments/assets/eac865f7-25e3-414d-927e-b479df2ee289" />   
可以和广度优先算法对比着看   

---------------
dijkstra算法是向各个方向均匀的扩散，扩展成圆球的形状，没有任何关于终点的信息，是一种盲目的向各个方向穷举的行为
---------------
因此，可以结合启发式搜索的贪心算法 他会对终点有一个guess，然后结合dijkstra最优性的一个特点
---------->>>>>>>>>>>  A* 算法

2）A*算法：   
dijkstra with a heuristic           [和dijkstra 算法的框架是完全一样的]   
{   
   accumulated cost:   
   g(n): the current best estimates of the accumulated cost from the start state to node "n"   

   heuristic:   
   h(n): the estimated least cost from node n to goal state     [从当前节点到终点估计出来的一个代价]   

   the least estimated cost from start state to goal passing through node "n" is    
   f(n) = g(n) + h(n)   

   strategy: expand the node with cheapest f(n) = g(n) + h(n)   
   --update the accumulated costs g(m) for all unexpanded neighbors "m" of node "n"     [更新]   
   --a node has been expanded/visited is guaranteed to have the smallest cost from the start state [最优性保证]   
}   


### A* algorithm
{   
   maintain a priority queue to store all the nodes to be expand   
   the heuristic function h(n) for all nodes are pre-defined   
   the priority queue is initialized with the the start state Xs （用Xs初始化优先队列）  
   assign g(Xs) = 0, and g(n) = infinite for all other nodes in the graph   

   Loop:  
      if the queue is empty,return FALSE;break;  
      remove the node "n" with the lowest f(n) = g(n) + h(n) from the priority queue   
      mark node n as expanded   
      if the node "n" is the goal state, return TRUE;break;   
      for all unexpaned neighbor "m" of node "n"   
         if g(m) = infinite   
            g(m) = g(n) + Cnm  
            push node "m" into the queue   
         if g(m) > g(n) + Cnm   
            g(m) = g(n) + Cnm   
      end
  End Loop       
   
}   

## 那如何保证A*的最优性呢？   
<img width="1029" height="560" alt="image" src="https://github.com/user-attachments/assets/6065ac0c-59a5-4c87-aa05-cb5b8ed8926e" />
we need the estimate (h(n)) to be less than actual least cost to goal for all nodes   
对于每个节点估计出来的cost(h)  要小于到达最后目标的真实cost。   

为保证A*最优性，需要对启发式函数进行设计：   
## Admissble heuristic 可接受的启发式函数   

-----
对于任何一个节点，我估计出来的可能会花费的cost,是要小于真实的cost的  [h < h*(实际cost)]——————> 满足这个条件的话，最后A*算法的结果就是最优的   
-----
